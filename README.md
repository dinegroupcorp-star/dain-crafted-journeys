# 오후 2시 · Owhoo 2 — 낮술 지도 프로토타입

> 여유, 한가, 자유의 최고 기준은 낮술

성수 · 을지로·종로 · 마포의 **낮술 매장 100곳**을 지도에서 바로 확인하는 모바일 웹앱(PWA) 프로토타입입니다.
'모두의 주차장'의 UX(지도 위 상태 핀 → 바텀시트 → 즉시 행동)를 낮술 맥락에 맞게 옮겼습니다.

## 지금 열어보기
https://dinegroupcorp-star.github.io/owhoo2-prototype/

휴대폰 Safari/Chrome에서 열고 **홈 화면에 추가**하면 앱처럼 전체 화면으로 실행됩니다.

## 핵심 기능

| 기능 | 설명 |
| --- | --- |
| 기준 시각 토글 | `지금 시간` / `오후 2시` 를 바꾸면 100곳의 영업중·브레이크·오픈 전·종료 상태가 전부 다시 판정됩니다 |
| 지도 핀 | 확대하면 매장명 알약 핀, 축소하면 권역별 매장 수 클러스터. 핀 색 = 그 시각의 영업 상태 |
| 권역·필터 칩 | 전체/성수/을지로·종로/마포 + 바로 가능·브레이크X·테라스 + 주종(맥주·와인·전통주·하이볼·사케·칵테일) |
| 검색 | 매장명·안주(시그니처 메뉴)·주종·동네로 검색 |
| 바텀시트 | 상태 뱃지, 평일/주말 영업시간, 브레이크, 테라스, 시그니처, 낮술 포인트, 오후 2시 기준 재판정 |
| 낮술 패스 | 프로토타입용 웰컴 쿠폰 발급 데모(1잔 할인·안주 서비스). 발급 내역은 브라우저에 저장됩니다 |
| 외부 연결 | 네이버 지도 길찾기 · 전화 · 인스타그램 |
| 목록/지도 전환 | 카드 목록에서 바로 상세로 이동, 현재 위치·권역 점프 버튼 |

## 데이터
- `data/stores.json` — 낮술매장 마스터DB 100곳(성수 35 · 을지로·종로 35 · 마포 30), 수집 2026-11-07
- 좌표: 도로명 주소를 카카오 지오코딩으로 변환(100/100 확보)
- 영업시간·브레이크타임은 점주가 수시로 변경하므로 방문 전 확인이 필요합니다.

## 기술
정적 사이트. Leaflet 1.9 + CARTO Voyager 타일(API 키 불필요), 바닐라 JS, `manifest.json` + 서비스워커로 PWA 지원.
